# CineWeave

### Weave Intelligence Into Cinema.

> A visual AI cinematic workflow studio where ideas become cinematic experiences.
> Built for the **GMI Cloud × MiniMaxathon 2026**.

---

## What Is CineWeave?

CineWeave is a **visual cinematic workflow studio** — not a text-to-video generator, not a ChatGPT wrapper, not a generic workflow builder.

It's a new product category: a **visual node-based AI production environment** where creators design how intelligence flows through a cinematic pipeline.

You connect MiniMax models together. You direct how reasoning, video, voice, and music are orchestrated. The result is a production pipeline that transforms a raw idea into a cinematic experience — with every step reasoned, directed, and generated by AI.

---

## The Problem

AI generation tools are isolated.

Creators jump between:
- A language model for writing
- A video generator for footage
- A TTS tool for narration
- A music generator for the score

There is no visual way to **design how intelligence flows between them**. There is no production pipeline. There is no reasoning layer that connects them.

---

## The Solution

```
IDEA
  ↓
MiniMax M3 — Creative Director
  ↓
CINEMATIC BLUEPRINT
  ↓
MiniMax H3 ────────────────→ VIDEO
  ├── MiniMax Speech 2.8 ──→ NARRATION
  └── MiniMax Music 3.0 ───→ SCORE
                               ↓
                         CINEMATIC OUTPUT
```

CineWeave connects these models in an intelligent pipeline. M3 reasons about the idea. H3 generates the footage. Speech 2.8 creates the narration. Music 3.0 composes the score. All from one visual workflow.

## MiniMax Models Used

### 🧠 MiniMax M3 — Creative Director
**Provider:** OpenRouter (`minimax/minimax-m3:free`)

M3 is the reasoning engine of CineWeave. It transforms a raw creative idea into a structured **Cinematic Blueprint** containing:

- Story direction, genre, tone, visual language
- Emotional arc (opening → escalation → climax → resolution)
- Scene-by-scene breakdown with camera direction, lighting, and emotion
- A precise H3 video generation prompt
- A complete music brief with structural arc
- Narration text with emotional delivery guidance

M3 isn't asked to "improve a prompt." It functions as an actual **creative reasoning layer** — making narrative decisions, planning camera work, and designing the emotional journey.

**Example output:**
```json
{
  "title": "The Last Call",
  "creative_direction": {
    "genre": "Crime Noir",
    "tone": "Dark and tense",
    "visual_language": "Rain-soaked neon realism"
  },
  "emotional_arc": {
    "opening": "Quiet resignation",
    "escalation": "Growing dread",
    "climax": "Sudden revelation",
    "resolution": "Silence and uncertainty"
  },
  "scenes": [...],
  "h3_primary_prompt": "...",
  "music_brief": {...},
  "narration": {...}
}
```

---

### ⚡ MiniMax M2.7 — Workflow Assistant
**Provider:** OpenRouter (`minimax/minimax-m2.7:free`)

M2.7 serves as the fast workflow intelligence layer:
- Validates workflow connections
- Detects missing inputs or broken dependencies
- Refines and optimizes prompts for downstream models
- Suggests improvements to workflow configurations

M2.7 makes the workflow feel **responsive and intelligent** — it acts between nodes to catch problems before generation begins.

---

### 🎬 MiniMax H3 — Cinematic Video
**Provider:** GMI Cloud (`MiniMax-H3`)

The cinematic video generation engine. H3 receives precisely structured prompts crafted by the M3 reasoning pipeline — not random user input.

- 2K resolution video generation
- 5–15 second clips, multiple aspect ratios
- Async generation with real-time status polling
- First/last frame image-to-video support

CineWeave makes it visible that the H3 prompt has a **lineage**: User Idea → M3 Reasoning → Scene Direction → H3 Prompt → Generated Video.

---

### 🎙 MiniMax Speech 2.8 — Narration Engine
**Provider:** GMI Cloud (`minimax-tts-speech-2.8-hd`)

Cinematic narration and character voice generation:
- Multiple voice personas
- Emotional delivery control: `calm`, `dramatic`, `fearful`, `angry`, `surprised`
- Narration text sourced from M3's creative blueprint
- Async job polling with audio playback in-node

---

### 🎵 MiniMax Music 3.0 — Score Composer
**Provider:** GMI Cloud (`minimax-music-3.0`)

Complete cinematic soundtrack generation:
- Receives M3's structured music brief (opening → middle → climax → ending)
- Lyrics support with structural tags: `[Intro]`, `[Verse]`, `[Chorus]`, `[Bridge]`, `[Outro]`
- Full MP3 output with in-node audio playback
- Style prompt from M3's emotional arc analysis

## Architecture

```
┌─────────────────────────────────────────────────────────┐
│                     CineWeave                           │
│                                                         │
│  Frontend (React + Vite + TypeScript)                   │
│  ┌─────────────┬──────────────────┬──────────────────┐  │
│  │   Sidebar   │  Workflow Canvas │  Inspector Panel │  │
│  │  Node Lib   │  (@xyflow/react) │  (per-node cfg)  │  │
│  │  Templates  │                  │                  │  │
│  └─────────────┴──────────────────┴──────────────────┘  │
│                                                         │
│  State: Zustand (workflowStore)                         │
│  Execution Engine: Topological sort + async polling     │
│  Animations: Framer Motion                              │
└─────────────────────────────────────────────────────────┘
                         │
                         │ HTTP /api/*
                         ▼
┌─────────────────────────────────────────────────────────┐
│            Express Backend (server/index.js)            │
│                                                         │
│  POST /api/m3/direct    → OpenRouter (M3)               │
│  POST /api/m27/assist   → OpenRouter (M2.7)             │
│  POST /api/h3/generate  → GMI Cloud (H3)                │
│  POST /api/speech/generate → GMI Cloud (Speech 2.8)     │
│  POST /api/music/generate  → GMI Cloud (Music 3.0)      │
│  GET  /api/gmi/status/:id  → GMI Cloud (polling)        │
│                                                         │
│  API keys stored in .env — never exposed to frontend    │
└─────────────────────────────────────────────────────────┘
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
    OpenRouter      GMI Cloud      GMI Cloud
    M3 / M2.7       H3 Video       Speech/Music
```

### Execution Flow

When you click **Run Workflow**:

1. **Validate** — checks graph has required nodes and connections
2. **Sort** — topological sort resolves dependency order
3. **Execute** — each node runs in order, passing structured outputs downstream
4. **Poll** — async jobs (H3, Speech, Music) are polled until complete
5. **Update** — each node updates with results in real-time

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/cineweave.git
cd cineweave
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

```bash
cp .env.example .env
```

Open `.env` and add your API keys:

```env
# OpenRouter API Key (for MiniMax M3 and M2.7)
# Get your key at: https://openrouter.ai/keys
OPENROUTER_API_KEY=sk-or-...

# GMI Cloud API Key (for MiniMax H3 Video, Speech 2.8, Music 3.0)
# Get your key at: https://console.gmicloud.ai
GMI_API_KEY=gmi-...
```

### 4. Start the development server

```bash
npm run dev
```

This starts both the frontend (Vite on `localhost:5173`) and backend (Express on `localhost:3001`) concurrently.

Open [http://localhost:5173](http://localhost:5173)

## Using CineWeave

### Quick Start: Demo Workflow

1. Click **"✨ Open Demo Workflow"** on the landing page
2. The Mumbai Noir demo loads: *"A former boxer walks alone through a rain-soaked Mumbai street at midnight..."*
3. Click **"Run Workflow"** in the toolbar
4. Watch the pipeline execute in real-time

### Building Your Own Workflow

1. **Load a template** from the sidebar (Cinematic Trailer, Music Video, AI Short Film)
2. **Click the Idea node** → enter your creative concept, genre, and mood in the Inspector Panel
3. **Connect nodes** by dragging from output handles to input handles
4. **Configure nodes** individually using the Inspector Panel on the right
5. **Click Run Workflow** — watch M3 reason, H3 generate, Speech narrate, Music compose

### Templates

| Template | Pipeline |
|----------|----------|
| 🎬 Cinematic Trailer | Idea → M3 → H3 + Speech + Music → Output |
| 🎵 Music Video | Concept → M3 + M2.7 → Music + H3 → Output |
| 🎭 AI Short Film | Story → M3 + M2.7 → Scenes + Speech + Music → Film |

## API Security

All API keys are stored in `.env` and accessed **only server-side**. The frontend never sees them.

```
Frontend → /api/* → Express Server → OpenRouter / GMI Cloud
```

Never commit your `.env` file. It is in `.gitignore` by default.

## Design Philosophy

CineWeave uses a restrained, cinematic design language:

- **Near-black charcoal** backgrounds — professional creative software feel
- **Cinematic violet** accent (`#8b5cf6`) — the primary creative color
- **Warm amber** for generation activity
- **Muted emerald** for success states
- No excessive gradients, no rainbow colors, no generic AI sparkle

The interface should feel like a **premium creative tool**, not a demo.
